# Python Environment Picker (penv)

Handling multiple python projects in your system can be tedious; this project seeks to simplify this by providing the ability to create, delete, activate environments and some more, a very basic project.

## Assumptions
The tool makes considerable assumptions about the use case; mainly, it assumes that the user has **a main directory that houses multiple environments**, in addition to:
- Windows OS.
- You have python installed and added to PATH.

## Download instruction
Download the **[penv.zip](https://github.com/MonT97/python_environment_picker/releases/tag/stable )** from the **releases** section.

## Installation
Extract the zip file, click/launch the **[install.bat]** file, then follow the on-screen dialogue.

## Usage
This is simple enough; just follow the initial instructions.
