# Python Environment Picker (penv)

Handeling multiple python projects in your system can be tedious, this project seeks to simplify this by providing the ability to create, delete, activate environments and some more, a very basic project.

## Assumbtions
The tool makes conciderable assumptions about the use case, mainly, it assumes that the user has **a main directory that houses multiple environments**, in addition to:
- Windows OS.
- You have python installed and added to PATH.

## Download instruction
Download the **[penv.zip](https://github.com/MonT97/python_environment_picker/releases/tag/stable)** from the **releases** section.

## Installation
Extract the zip file then click/launch the **[install.bat]** file then follow the on-screen dialouge.

## Usage
This is simple enough, just follow the initial instruction instructions.
